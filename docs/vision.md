# Low Tide vision

Architect stamp, 2026-08-20.

This is later. It is not a backlog and not this week's ticket. Phase 0 stays one cove. The next cut is a playable cove, not more paper. See `docs/roadmap.md`.

The game is a small no-combat exploration for 2–4 friends. Knowledge is the only progression. The map can lie. Tide is a door you stand on, not a story you are told.

Chair test: if a thing is not good enough, fix it or cut it. Do not give the player a language the world does not have. If the visuals click, no backstory.

## Gate

Nothing below opens until a stranger can finish the named cove without a lecture. Day-30 stranger gate is a quality bar, not a calendar. If they need a HUD, a sign, or Skipper to know when they can go, the cove is not done.

## After the cove is a game (same beach)

All of this stays inside the named cove. Do not add a second beach, a tutorial annex, or a fourth plane to make these true.

1. Journal still never grades. After the closed case, 1–2 questions that never batch-validate. Extra silence. Not a recut of an 8–12 fact table.
2. Weather-will: one new Clock mood on the same water (surge, neap, or fog). Same jetty. Tide is the companion you cannot command. Not a creature. Not a 4-phase table.
3. Pins readable from across the beach (who, which tide, taught vs walked) without a menu. If they need a map, the pin failed the chair test.
4. One irreversible last tide that permanently changes one lock. Finite ending. Anti-Sky. No live calendar.
5. Closed case cannot stamp at camp unless the split group is together at slack. Reunion is load-bearing. Local/invite only. No stranger matchmaking.

Phone/camp/walk, sleep-as-save, friend channels, and a Clock API wait on this same gate. They are not a reason to recut the mesh.
